Việc theo giai đoạn

Đồng bộ máy tính ↔ điện thoại

GitHub Pages chỉ host app, không lưu tick. Tick nằm trên từng trình duyệt. Để tự gộp giữa các máy, dùng một Gist riêng (file JSON trên GitHub, không phải trang Pages).

  1. Tạo token: GitHub → Settings → Developer settings → Personal access tokens → Classic → gist → copy token.
  2. Trên máy tính: dán token → Tạo kho đồng bộ. Copy mã Gist.
  3. Trên điện thoại: dán cùng token + mã Gist → Lưu và tải.

Token chỉ lưu trên máy bạn, không đưa lên repo. Đừng đánh dấu repo chứa token. Token classic chỉ cần quyền gist.

Chưa nối cloud. Tick vẫn lưu local trên máy này.
